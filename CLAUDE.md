# Projektnotizen

Statische Exposé-Website (Immobilienverkauf), kein Build, keine npm-Abhängigkeiten.

- **Objekt**: Einfamilienhaus Wiesenweg 4, 55592 Raumbach (Bauherr laut Plan: Markus Nau). Quellen: Bauantragspläne (PDF, einraum Kaiserslautern, Jan 2026: UG/EG/DG, Lageplan, Ansichten, Schnitt) und 21 Insta360-Aufnahmen vom 29.10.2026 (DNG, je 7680×3840 Panorama + 3840×2160 Flachbild) auf Bens USB-Stick „MARKUS NAU“. Offene Werte stehen als „–“.
- **Bild-Pipeline** (Werkzeuge im Session-Scratchpad, Quellen `brighten.swift`, `reframe.swift`, `pdfpages.swift`; /tmp wird nach 3 Tagen geleert, bei Bedarf neu kompilieren): DNG → `sips` JPEG → `brighten` (+0,3…1,1 EV, Schatten) → Panorama 5120 px q78 + `-vorschau.jpg` 1024 px; Galeriefotos werden mit `reframe` (Kugelbild → Perspektive, yaw/pitch/hfov je Szene) aus dem Panorama gerendert, 1800×1200 + `-klein.jpg` 800 px; `hero.jpg` aus dem Terrassen-Panorama. Dateinamen = Aufnahmezeit (HHMMSS).
- **Inhalte**: ausschließlich in `content/property.js` (`window.PROPERTY`, deutsche Schlüssel, kommentiert). Bei Änderungswünschen an Texten/Bildern/Pins zuerst dort ansetzen, nicht im Markup.
- **Aufbau**: `index.html` ist nur ein Gerüst; `js/render.js` füllt Hero/Fakten/Galerie/Kontakt, `js/plan.js` den Grundriss, `js/tour.js` den 360°-Rundgang (Pannellum 2.5.6 lokal unter `vendor/pannellum/`, mit Patch – siehe dortige README; kein CDN, weil Hoster-CSPs `blob:` blocken können), `js/lightbox.js` die Galerie-Ansicht. Klassische Scripts (kein ESM), damit auch ohne Server-Konfiguration alles läuft.
- **Design**: klassisches Makler-Exposé nach Bens Stilvorgabe (seriös, zeitlos, keine KI-Landingpage-Optik): Weiß mit cremefarbenen Bändern (`.section--band`: Grundriss, Kontakt; Kennzahlenleiste), Anthrazit, Dunkelblau `--accent` für Überschriften, Buttons, Pins und die Fußzeile, warmes Gold `--accent-2` nur für kleine Kennzeilen/Listenüberschriften (Ben fand die reine Blau-Grau-Version „traurig“), Playfair Display für Überschriften, Inter für Fließtext (beide lokal in `assets/fonts/`, Einbindung `css/fonts.css`, keine Google-Anfrage), feine Trennlinien statt Boxen, keine Schatten, keine Verläufe, keine Scroll-Animationen, keine Icons/Emoji, Buttons rechteckig mit 3 px Radius, Überschriften nicht überdimensioniert. Struktur: Kopfzeile (Wortmarke links, Menü rechts) → großes Foto → Titel/Standort/Preis → Kennzahlenleiste → Beschreibung (Lesespalte) mit Daten zweispaltig darunter → Energieausweis → Bilder → Grundriss & 360° → Lage → Kontakt (Ansprechpartner, E-Mail-/Telefon-Button; Ben will bewusst kein Formular und keine Objektnummer). Tokens oben in `css/styles.css`. Bitte beim Erweitern beibehalten.
- **Grundrisse**: aus dem Bauantrags-PDF gerendert (Seiten 2–4, gedreht, zugeschnitten; `assets/floorplans/{untergeschoss,erdgeschoss,dachgeschoss}.jpg`). Etagen haben `kurz` (EG/UG/DG) und optional `weitere` (Szenen ohne Pin, z. B. Außen/Nebengebäude) – die erscheinen in der Raumliste unter „Ohne Punkt im Plan“ und in den Rundgang-Chips mit Etagenkürzel.
- **Pins/Hotspots**: `?pins` in der URL → Klick im Plan kopiert x/y in %, Klick im Panorama loggt pitch/yaw (Pannellum `hotSpotDebug`).
- **Lokal testen**: `python3 -m http.server 4173` (siehe `.claude/launch.json`, Name `expose`).
- **Deploy**: GitHub Pages aus `main` / root. `.nojekyll` liegt bei.
