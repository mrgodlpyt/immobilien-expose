# Projektnotizen

Statische Exposé-Website (Immobilienverkauf), kein Build, keine npm-Abhängigkeiten.

- **Inhalte**: ausschließlich in `content/property.js` (`window.PROPERTY`, deutsche Schlüssel, kommentiert). Bei Änderungswünschen an Texten/Bildern/Pins zuerst dort ansetzen, nicht im Markup.
- **Aufbau**: `index.html` ist nur ein Gerüst; `js/render.js` füllt Hero/Fakten/Galerie/Kontakt, `js/plan.js` den Grundriss, `js/tour.js` den 360°-Rundgang (Pannellum 2.5.6 lokal unter `vendor/pannellum/`, mit Patch – siehe dortige README; kein CDN, weil Hoster-CSPs `blob:` blocken können), `js/lightbox.js` die Galerie-Ansicht. Klassische Scripts (kein ESM), damit auch ohne Server-Konfiguration alles läuft.
- **Design**: klassisches Makler-Exposé nach Bens Stilvorgabe (seriös, zeitlos, keine KI-Landingpage-Optik): Weiß mit cremefarbenen Bändern (`.section--band`: Grundriss, Kontakt; Kennzahlenleiste), Anthrazit, Dunkelblau `--accent` für Überschriften, Buttons, Pins und die Fußzeile, warmes Gold `--accent-2` nur für kleine Kennzeilen/Listenüberschriften (Ben fand die reine Blau-Grau-Version „traurig“), Playfair Display für Überschriften, Inter für Fließtext (beide lokal in `assets/fonts/`, Einbindung `css/fonts.css`, keine Google-Anfrage), feine Trennlinien statt Boxen, keine Schatten, keine Verläufe, keine Scroll-Animationen, keine Icons/Emoji, Buttons rechteckig mit 3 px Radius, Überschriften nicht überdimensioniert. Struktur: Kopfzeile (Wortmarke links, Menü rechts) → großes Foto → Titel/Standort/Preis → Kennzahlenleiste → Beschreibung (Lesespalte) mit Daten zweispaltig darunter → Energieausweis → Bilder → Grundriss & 360° → Lage → Kontakt mit Anfrageformular. Tokens oben in `css/styles.css`. Bitte beim Erweitern beibehalten.
- **Formular**: `js/form.js`; ohne `kontakt.formular.endpoint` wird eine mailto:-Mail vorbereitet, mit Endpunkt (z. B. Formspree) per fetch gesendet. Honeypot-Feld `website`.
- **Pins/Hotspots**: `?pins` in der URL → Klick im Plan kopiert x/y in %, Klick im Panorama loggt pitch/yaw (Pannellum `hotSpotDebug`).
- **Lokal testen**: `python3 -m http.server 4173` (siehe `.claude/launch.json`, Name `expose`).
- **Deploy**: GitHub Pages aus `main` / root. `.nojekyll` liegt bei.
